# School Management System

A desktop-based management tool designed to streamline administrative tasks such as student enrollment and course management. This project focuses on implementing *MVC (Model-View-Controller)* architecture and efficient data handling.

## Features
* **Student Management:** Create, view, and delete student records.
* **Course Administration:** Manage course catalogs and credit assignments.
* **Responsive UI:** Built with JavaFX for a smooth user experience.

## Tools & Technologies
* **Language:** Java 17+
* **Framework:** JavaFX (UI Rendering)
* **Build Tool:** Maven (Dependency Management)
* **Design:** FXML & CSS (View separation)
* **IDE:** IntelliJ IDEA

## Project Structure
The project follows a standard Maven directory structure:
* `src/main/java`: Contains the backend logic, models, and controllers.
* `src/main/resources`: Contains FXML layouts and styling.
* `models`: Data structures for Students, Courses, and the SchoolManager.
* `controllers`: Logic handling for UI interactions.

## Getting Started
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Ensure the JavaFX SDK is configured in your project settings.
4. Run the `Launcher.java` class to start the application.
